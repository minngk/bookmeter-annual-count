# 読書メーター 年間冊数

読書メーター（bookmeter.com）の今年の読書冊数をブラウザのバッジに表示する Chrome 拡張機能です。

## 機能

- 今年の読書冊数をツールバーのバッジにリアルタイム表示
- 1日1回自動更新
- ポップアップから手動更新も可能

## インストール

### Chrome Web Store（準備中）

### 手動インストール（開発者向け）

1. このリポジトリをクローンまたは ZIP でダウンロード
2. Chrome で `chrome://extensions/` を開く
3. 右上の「デベロッパーモード」をオン
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. ダウンロードしたフォルダを選択

## 使い方

1. 拡張機能をインストールすると設定画面が開きます
2. Chrome 右上のパズルピースアイコン（拡張機能）をクリックし、「読書メーター 年間冊数」のピンアイコンをクリックしてツールバーに固定します
3. 読書メーターのユーザーID（プロフィールURL の数字部分）を入力して保存
4. バッジに今年の読書冊数が表示されます
